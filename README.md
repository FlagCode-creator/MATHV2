# Math Quest V2 — ผจญภัยคณิตศาสตร์

เกมผจญภัย + สู้บอส แยก repo ออกมาจาก V1 (Mathematics-Challenge) — ไม่แตะไฟล์เดิม
เปิดเล่นที่ `index.html` (ถ้าเปิด GitHub Pages: `https://flagcode-creator.github.io/MATHV2/`)

## ระบบเกม
- **9 ดินแดน / 26 ด่าน (A–Z)** — แต่ละหัวข้อคือมอนสเตอร์ 1 ตัว ผ่านตามลำดับ แล้วสู้บอสประจำดินแดนเพื่อปลดล็อกดินแดนถัดไป
- **ต่อสู้แบบผลัดตา** — ตอบถูก = โจมตี, ตอบเร็ว (แถบเวลาสีทอง) = คริติคอล ×1.5, ตอบถูกติดกัน = คอมโบ (+10%/ข้อ สูงสุด +50%)
  ตอบผิด/หมดเวลา = มอนสเตอร์สวนกลับ พร้อมเฉลยและวิธีคิดทันที
- **บอส** — มี 2 ร่าง (ครึ่ง HP แล้วคลั่ง) และชาร์จท่าไม้ตายทุก 3 ข้อ (ตอบถูกตอนชาร์จ = ขัดจังหวะ)
- **บอสใหญ่: ครูแฟล็ก ร่างเดือด** — 3 ร่าง โจทย์ผสมทุกหัวข้อ ใช้ภาพมาสคอตจาก `assets/mascot/`
- **เลเวล / EXP / เหรียญ / ดาว 1–3** (ดาวตาม HP ที่เหลือตอนชนะ) — ชนะด่านเดิมซ้ำ โจทย์จะเริ่มยากขึ้น
- **ร้านค้า**: ยาฟื้นพลัง, โล่, ลูกแก้ว 50/50, นาฬิกาทราย · **คำใบ้** ฟรีแต่ข้อนั้นตีเบาลงครึ่งหนึ่ง
- **ภาพพิกเซลอาร์ต** — มอนสเตอร์ บอส และตัวละครผู้เล่น (มีชุดนักเรียนไทยด้วย) เข้ากับภาพครูแฟล็ก
- **ครูแฟล็กเป็นไกด์** — เนื้อเรื่องเปิด, บทพูดตอนชนะ/แพ้/เลเวลอัป ใช้ภาพอารมณ์ทั้ง 18 แบบ

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าจอทั้งหมด |
| `css/game.css` | สไตล์แนวพิกเซล RPG |
| `js/util.js` | ตัวช่วยทั่วไป (`rng`, `$`, `esc`, toast) |
| `js/questions.js` | คลังโจทย์ — คัดลอกจาก V1 + แก้ระบบสมการ (N) ไม่ให้สุ่มได้เส้นขนาน + เติมตัวเลือกให้โจทย์ปัญหา |
| `js/sprites.js` | ภาพพิกเซลอาร์ตวาดด้วยโค้ด: มอนสเตอร์ 26 ตัว, บอส 8 ตัว, ตัวละครผู้เล่น 12 แบบ (1 ตัวอักษร = 1 พิกเซล, ระบบเติมเส้นขอบ/แสงเงาให้เอง) |
| `js/data.js` | ดินแดน มอนสเตอร์ บอส ไอเทม ค่าพลัง และบทพูด — **ปรับสมดุลเกมที่ไฟล์นี้** |
| `js/save.js` | บันทึกความก้าวหน้าใน localStorage (key `mq2_...` ไม่ชนกับ V1) |
| `js/audio.js` | เสียงเอฟเฟกต์สังเคราะห์ |
| `js/game.js` | หน้าจอ แผนที่ ฉากต่อสู้ ร้านค้า ตัวละคร |

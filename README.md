# Math Quest V2 — ผจญภัยคณิตศาสตร์

เกมผจญภัย + สู้บอส แยก repo ออกมาจาก V1 (Mathematics-Challenge) — ไม่แตะไฟล์เดิม
เปิดเล่นที่ `index.html` (ถ้าเปิด GitHub Pages: `https://flagcode-creator.github.io/MATHV2/`)

## ระบบเกม
- **9 ดินแดน / 26 ด่าน (A–Z)** — แต่ละหัวข้อคือมอนสเตอร์ 1 ตัว ผ่านตามลำดับ แล้วสู้บอสประจำดินแดนเพื่อปลดล็อกดินแดนถัดไป
- **ต่อสู้แบบผลัดตา** — ตอบถูก = โจมตี, ตอบเร็ว (แถบเวลาสีทอง) = คริติคอล ×1.5, ตอบถูกติดกัน = คอมโบ (+10%/ข้อ สูงสุด +50%)
  ตอบผิด/หมดเวลา = มอนสเตอร์สวนกลับ พร้อมเฉลยและวิธีคิดทันที
- **บอส** — มี 2 ร่าง (ครึ่ง HP แล้วคลั่ง) และชาร์จท่าไม้ตายทุก 3 ข้อ (ตอบถูกตอนชาร์จ = ขัดจังหวะ)
- **บอสใหญ่: ครูแฟล็ก ร่างเดือด** — 3 ร่าง โจทย์ผสมทุกหัวข้อ ใช้ภาพมาสคอตจาก `assets/mascot/`
- **เลเวล / EXP / เหรียญ / ดาว 1–3** (ดาวตาม HP ที่เหลือตอนชนะ) — ชนะด่านเดิมซ้ำ โจทย์จะเริ่มยากขึ้น
- **ร้านค้า**: ยาฟื้นพลัง, โล่, ลูกแก้ว 50/50, นาฬิกาทราย · **คำใบ้** ฟรีแต่ข้อนั้นตีเบาลงครึ่งหนึ่ง
- **ภาพพิกเซลอาร์ต** — มอนสเตอร์ บอส และตัวละครผู้เล่น (มีชุดนักเรียนไทยด้วย) เข้ากับภาพครูแฟล็ก
- **ฉากหลังประจำดินแดน** — ใช้ในฉากต่อสู้ แผนที่ หน้าต่างดูศัตรู และหน้าแรก
- **ครูแฟล็กเป็นไกด์** — เนื้อเรื่องเปิด, บทพูดตอนชนะ/แพ้/เลเวลอัป ใช้ภาพอารมณ์ทั้ง 18 แบบ

## โหมดผจญภัย (ต้นแบบดินแดนที่ 1)
เข้าจากปุ่ม "🧭 เดินสำรวจทุ่งหญ้าจำนวน" บนแผนที่โลก — แผนที่แบบกดเลือกด่านเดิมยังเล่นได้ตามปกติ
- **เดินสำรวจแบบ RPG มุมบน**: ปุ่มลูกศร + ปุ่ม A บนจอ (มือถือ) หรือ ลูกศร/WASD + Space (คอม)
- **หมู่บ้านเริ่มต้น**: ครูแฟล็ก (ให้ภารกิจ) ร้านค้า โรงแรม (ฟื้น HP ฟรี) และชาวบ้าน
- **ทุ่งหญ้า 5 พื้นที่ = 5 หน่วยเนื้อหา** (บวก ลบ คูณ หาร ผสม) + ลานบอส — มอนสเตอร์เดินอยู่บนแผนที่ เดินชนแล้วเข้าฉากต่อสู้
- **ภารกิจ + ปริศนาเปิดทาง**: ปราบมอนสเตอร์ในพื้นที่ 3 ตัว แล้วไขปริศนา
  - ทุ่งบวก: ผลรวมเลขบนแผ่นหิน 3 แผ่น · ทุ่งลบ: ไม้ที่ต้องหาเพิ่มเพื่อซ่อมสะพาน · ทุ่งคูณ: นับแครอททั้งแปลง (แถว × ต้น) เพื่อเปิดหีบเอากุญแจ
  - ทุ่งหาร: แบ่งเหรียญเท่า ๆ กัน · ทุ่งผสม: พื้นที่ห้องหินโบราณ (กว้าง × ยาว) · ตัวเลขปริศนาสุ่มต่อผู้เล่น
  - ตอบผิด 2 ครั้งจะมีคำใบ้ · มีหีบโบนัสที่ต้องคำนวณรหัส
- **HP ต่อเนื่องระหว่างการต่อสู้** (พักที่โรงแรมเพื่อฟื้น) · แพ้แล้วกลับมาที่หมู่บ้านโดยไม่เสียของ
- **กราฟิกแบบละเอียด + แนวนอน**: ตัวละคร 16×24 เดินได้ 4 ทิศ (ทิศละ 3 เฟรม), ขอบหญ้า/ทาง/น้ำกลมกลืน, บ้านทั้งหลัง, ต้นไม้ใหญ่, น้ำพุ, เสาไฟ · จอแนวนอนเห็นแผนที่กว้างขึ้น (แนวตั้งยังเล่นได้)
- **ใส่ภาพ PNG ของครูเองได้** ดูวิธีที่ `assets/custom/README.md`
- **ต้นไม้ทักษะ** 3 สาย (โจมตี ป้องกัน ปัญญา) สายละ 4 ขั้น — เลเวลอัป 1 ครั้ง = 1 แต้ม ใช้ได้ทั้งสองโหมด

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าจอทั้งหมด |
| `css/game.css` | สไตล์แนวพิกเซล RPG |
| `js/util.js` | ตัวช่วยทั่วไป (`rng`, `$`, `esc`, toast) |
| `js/questions.js` | คลังโจทย์ — คัดลอกจาก V1 + แก้ระบบสมการ (N) ไม่ให้สุ่มได้เส้นขนาน + เติมตัวเลือกให้โจทย์ปัญหา |
| `js/sprites.js` | ภาพพิกเซลอาร์ตวาดด้วยโค้ด: มอนสเตอร์ 26 ตัว, บอส 8 ตัว, ตัวละครผู้เล่น 12 แบบ (1 ตัวอักษร = 1 พิกเซล, ระบบเติมเส้นขอบ/แสงเงาให้เอง) |
| `js/backgrounds.js` | ฉากหลังพิกเซลของ 9 ดินแดน (ทุ่งหญ้า ป่า ถ้ำ ภูเขา หอคอย ทะเล ตลาด ปราสาท บัลลังก์) วาดด้วยโค้ด |
| `js/skills.js` | ต้นไม้ทักษะ: ข้อมูลทักษะ ผลต่อค่าพลัง และหน้าจออัปทักษะ |
| `js/explore-data.js` | แผนที่โหมดผจญภัย (หมู่บ้าน, ทุ่งหญ้า) NPC มอนสเตอร์ ประตู หีบ และปริศนา — **ออกแบบด่านเพิ่มที่ไฟล์นี้** |
| `js/explore.js` | เอนจินเดินสำรวจ: วาดแผนที่ การเดิน มอนสเตอร์ บทสนทนา ปริศนา และเชื่อมกับฉากต่อสู้ |
| `js/chars.js` | ตัวละครเดิน 4 ทิศ: แม่แบบร่าง + ทรงผม/หมวก/ชุด + สีของแต่ละอาชีพและ NPC |
| `js/tiles.js` | กราฟิกแผนที่: หญ้า ทาง น้ำ สะพาน พื้นหิน บ้านทั้งหลัง น้ำพุ ต้นไม้ พุ่มไม้ เสาไฟ |
| `js/custom-assets.js` | โหลดภาพ PNG ของครูเองจาก `assets/custom/manifest.json` (ถ้ามี) |
| `js/data.js` | ดินแดน มอนสเตอร์ บอส ไอเทม ค่าพลัง และบทพูด — **ปรับสมดุลเกมที่ไฟล์นี้** |
| `js/save.js` | บันทึกความก้าวหน้าใน localStorage (key `mq2_...` ไม่ชนกับ V1) |
| `js/audio.js` | เสียงเอฟเฟกต์สังเคราะห์ |
| `js/game.js` | หน้าจอ แผนที่ ฉากต่อสู้ ร้านค้า ตัวละคร |
